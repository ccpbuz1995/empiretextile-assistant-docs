EMPIRETEXTILE Assistant

Version 1.0.0 · Self-developed application for internal use

Purpose

EMPIRETEXTILE Assistant is an internal tool used by EMPIRETEXTILE to manage its own product offers and stock on Allegro. It reads the company's own listings, prepares changes, and applies them only after a manual confirmation.

What the application does

  • Reads the company's own offers, prices and stock levels.
  • Updates offer data (titles, descriptions, images, prices, quantities) after explicit approval.
  • Reads order status for the company's own shop, for reporting.

What it does not do

  • It does not operate on offers or accounts of other sellers.
  • It does not send messages to buyers automatically.
  • It does not store buyers' personal data beyond what is needed for order processing.

Access and security

  • Access uses OAuth 2.0 authorization of the company's Allegro account.
  • Credentials are stored on the company's own server and are not shared.
